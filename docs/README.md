# iPlay5 feature guides

Everything iPlay5 does, grouped by topic. The [main README](https://github.com/reefbarman/iPlay5#readme) has the highlights, install steps and first-run setup. The [changelog](https://github.com/reefbarman/iPlay5/blob/main/CHANGELOG.md) lists what changed in each release. These guides are also published at [reefbarman.github.io/iPlay5](https://reefbarman.github.io/iPlay5/).

| Guide                                                       | What's in it                                                                                                                              |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| [Consoles and setup](consoles-and-setup.md)                 | Finding and linking a PS5, PSN sign-in, waking, the console list, per-console settings, playing away from home                            |
| [Picture](picture.md)                                       | Resolution, bitrate, codecs, HDR, Fit/Zoom, upscaling and MetalFX, 120 Hz, frame generation, stats                                        |
| [Controllers](controllers.md)                               | Supported controllers, the PS button, DualSense feedback, rumble on other controllers and the phone, motion, gyro aiming, Controller Test |
| [Touch and virtual controls](touch-and-virtual-controls.md) | The touchscreen as a touchpad, on-screen controls and their options, Controls Guide                                                       |
| [Connection](connection.md)                                 | Auto bitrate, Optimise connection, network smoothing, Takion v20, reconnecting, app switching                                             |
| [Audio](audio.md)                                           | Game audio, interruptions and AirPods, microphone and party chat                                                                          |
| [The stream screen](stream-screen.md)                       | Corner shortcuts, the stream menu, phone battery and heat, typing on the phone, screenshots                                               |
| [iPhone Duo](iphone-duo.md)                                 | Inner and outer screens, folding, controller and shim recommendations                                                                     |
| [Help and troubleshooting](troubleshooting.md)              | Share diagnostics, frame capture, known limitations                                                                                       |

Settings paths in these guides look like **Settings › Display**. Open Settings from the gear on the console list, or during a stream from the top-right corner or by holding **Select + Start**. Most settings are also in the stream menu, so you can change them while you play.
